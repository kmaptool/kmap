# OSM Carto style — licence

The colours in `palette.txt` and the icons in `points.txt` come from
**openstreetmap-carto**, the stylesheet that draws openstreetmap.org itself. See
`PROVENANCE.md` for which files were read and how the icons were made.

    https://github.com/gravitystorm/openstreetmap-carto
    CC0 1.0 Public Domain Dedication

## What upstream states

The project's `LICENSE.txt`, read on 2026-09-08, says in full:

> This software and associated documentation files (the "Software") is released under the
> CC0 Public Domain Dedication, version 1.0, as published by Creative Commons. To the
> extent possible under law, the author(s) have dedicated all copyright and related and
> neighboring rights to the Software to the public domain worldwide. For avoidance of
> doubt, this includes the cartographic design. The Software is distributed WITHOUT ANY
> WARRANTY.

The sentence about cartographic design is the one that matters here, since a palette and a
set of icons are design rather than code. It is explicit, and it is why this style could be
transcribed at all.

Upstream credits the work to Andy Allan and contributors, based on original cartography by
Steve Chilton and others.

## What that means for you

CC0 is a dedication to the public domain, not a licence with conditions. There is nothing
to comply with: no attribution is required, no share-alike, and nothing forbids selling a
map built with this style. The credit kmap gives openstreetmap-carto is courtesy and
traceability, not obligation — this file included.

Note that this covers the *style* only. Map data is OpenStreetMap and stays under the ODbL
whatever style is drawn over it; see the repository's `NOTICE.md`.
