# The OpenTopoMap web look, on the type codes kmap's rules emit.
#
# Every colour, dash and pattern is OpenTopoMap's own raster style (CC-BY-SA):
# github.com/der-stefan/OpenTopoMap, mapnik/ at commit
# 60c50cb8329d67c8556cd9f25b4a8e50bfc19c91, the rule that applies at z16. A note names the
# file under mapnik/styles-otm/ (or mapnik/) and the lines of that rule. The codes are
# kmap's; each is drawn as OpenTopoMap draws the OSM features kmap's rules put on it, and
# named as Assets/styles/type-names.txt names it. PROVENANCE.md has the rules.
#
#   poly <code> <level> <day> <name>        level = draw order, 1 lowest
#   line <code> <width> <day> [casing] <name>
#
# A translucent colour is composited over their land colour #e0e0e0. Night colours are
# derived by kmap.
#
# Widths are not the original's: a line takes the whole width kmap's topoactive gives the
# same code, casing included, and a line topoactive leaves to the device has no row here
# or in graphics.txt. The original's width in a note is for the record.
#
# graphics.txt draws the dashes, line patterns and fill patterns, and clear sections for
# what OpenTopoMap does not draw. Its sections replace the flat colours here, which stay
# as a fallback. Attribution: (c) OpenTopoMap (CC-BY-SA).
